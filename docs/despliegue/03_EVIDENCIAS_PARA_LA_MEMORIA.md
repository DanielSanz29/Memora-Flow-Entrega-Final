# 3. Evidencias que deben añadirse a la memoria tras desplegar

Cuando la URL pública funcione, tomar capturas legibles y sustituir los apartados pendientes de la memoria.

## Capturas necesarias

1. Repositorio GitHub mostrando archivos principales y último commit.
2. Railway mostrando el servicio web y MySQL activos.
3. URL pública abierta en el navegador con la pantalla de inicio de sesión.
4. Panel de recepción con acceso a **Ver catálogos**.
5. Catálogo visual con ataúdes, flores y urnas.
6. Historial de órdenes y edición del estado.
7. Panel de gerencia con **Ver funerarios y recepcionistas**.
8. PDF descargado desde la URL publicada.
9. Endpoint `/api/health` respondiendo correctamente.

## Datos a insertar en la memoria

- URL del repositorio GitHub final.
- URL pública de Railway.
- Fecha de comprobación de los enlaces.
- Descripción breve del despliegue: un servicio web Docker que sirve React y Express, conectado a MySQL Railway.
- Sustitución del estado “pendiente de despliegue” por “comprobado” cuando se hayan realizado las pruebas anteriores.

## Nombre definitivo del PDF

Una vez incluidos los enlaces y capturas finales, exportar la memoria como:

```text
sanz_castillo_daniel_memoria_proyecto.pdf
```
